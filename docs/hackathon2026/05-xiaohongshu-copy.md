# 小红书公开介绍文案

## 标题

我把求职海投改成了人工确认

## 正文

找工作最磨人的，不一定是写简历。

更常见的是每天重复做这些事：打开一堆岗位，判断值不值得看，改一遍招呼语，记住聊到哪，HR 要简历时再临时找文件。

我做了 BossHunter，把这串流程接起来：

岗位预筛 → AI 看完整 JD 和简历做匹配分析 → 排序 → 生成个性化招呼语 → 人工确认 → 跟进状态 → 按岗位整理定制简历。

但我给它留了一条很明确的边界：

AI 可以帮我看、帮我写、帮我记，不能替我决定投不投。

所以发送前一定有人确认。真实版本默认本地运行，简历和 API Key 不需要交给一个陌生云服务；同时保留低频、时间窗、每日上限和停止机制。

这次参加 2026 外滩黑客松，我又补了一个公开评委模式。因为真实版本要连接本地 Chrome 和个人招聘平台账号，直接让评委用既不现实也不安全。

现在打开网页，不登录、不上传简历、不填 API Key，就能用一份匿名示例简历和 6 条模拟 JD，自己跑完评分、排序、招呼语、人工确认、状态漏斗和定制简历的关键闭环。所有公司、人物和结果都明确是模拟数据，也不会真的发出任何消息。

在线体验：
https://powerycy.github.io/BossHunter/

源代码：
https://github.com/powerycy/BossHunter

我不想做一个“替你多投几百份”的工具。更想做的是：让人少被重复动作拖住，把注意力留给真正值得判断的机会。
